# VelvetMedia — лендинг

Одностраничный сайт студии интернет-рекламы **VelvetMedia** (Набережные Челны).
SEO-продвижение сайтов в ТОП-10 Яндекс и Google с оплатой за результат.

## Стек

Чистый HTML + CSS + JavaScript, без сборки и зависимостей. Шрифт — Manrope (Google Fonts).

## Структура

```
index.html   — разметка лендинга
styles.css   — стили (тёмно-фиолетовая премиум-тема)
script.js    — модалка, формы, анимации появления, счётчики
```

## Секции

1. Шапка с навигацией и кнопкой звонка
2. Первый экран (hero) + форма заявки
3. Проблемы клиентов
4. Что мы предлагаем
5. Этапы работ по продвижению (6 шагов)
6. Что вы получите в результате
7. Цифры о компании (анимированные счётчики)
8. Почему выбирают нас
9. Блок «нет сайта — разработаем»
10. Контакты + форма расчёта
11. Подвал

## Запуск локально

Просто откройте `index.html` в браузере, либо поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages → Source: ветка с этими файлами, папка `/root`.
2. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Подключение форм

Сейчас отправка форм — заглушка (выводит данные в консоль и показывает уведомление).
Чтобы заявки приходили реально, отредактируйте функцию `sendLead` в `script.js`:
подключите [Formspree](https://formspree.io), свою CRM или Telegram-бота.
